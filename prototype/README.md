# 리틀부스 프로토타입 (HTML)

단일 HTML로 만든 화면·흐름 시안이에요. Flutter 앱(`app/`)을 만들기 전에 컨셉·디자인·기능을 확인하는 용도예요.
화면·기능 명세는 [docs/product/screens.md](../docs/product/screens.md)에 정리돼 있어요.

## 열기
`prototype/index.html`을 브라우저로 열어요. 같은 폴더의 `account-test1234.js`, `products/`가 함께 있어야 해요.
상단 "기기 미리보기"로 PC·태블릿·모바일 레이아웃을 바꿔 볼 수 있어요. 엑셀 기능은 cdnjs의 ExcelJS 4.4.0을 그때그때 불러와요(인터넷 필요).

## 로그인
| 방법 | 데이터 |
| --- | --- |
| 아이디 `test1234` (비밀번호는 아무 값) | 실제 기록: 여의도 음악축제(2026.10.24) + 8월 서코 일요일(일산 킨텍스 BJ04·BJ05) |
| [데모로 둘러보기] | 예시 데이터(망원·성수·한강·홍대 등 가상 행사, 내 이름 = 서진) |

프로토타입이라 비밀번호를 확인하지 않고, 새로 입력한 내용은 새로고침하면 사라져요(로그인 상태와 "내 이름"만 브라우저에 기억). 실제 인증·저장은 `backend/`(Firebase)에서 구현해요.

## 주요 기능 (v73 기준)
- **나의 행사**: 폴더형 카드, 운영 준비 → 운영 중 → 운영 종료, 운영 중 카드 글로우
- **새 행사 만들기**: 썸네일, 연·월 선택 달력, 지난 행사 준비안·반입 상품 불러오기
- **개요·준비**: 가설(글+사진) · 체크리스트/공지·현장 메모 블럭 · 반입 상품(재고에서 켜고 끄기)
- **판매 화면(POS)**: 상품 타일(사진), 주문 줄 안 옵션·수량, 할인, 결제수단(카드·현금·계좌이체·카카오페이), 방문 +1(시각 기록), 메모, 모바일 바텀시트
- **판매 기록**: 결제 내역(날짜·시:분:초·결제수단·상품·할인), 결제 내역 CSV
- **결과·회고**: 요약 · 일별/시간대별(꺾은선)/방문 시간대(5분 막대 + 시간당 추이) · 품목별 매출(누적 막대) · 판매 순위(상품/옵션/카테고리, 반입 대비 판매율·순수익, 6위부터 펼치기) · 결제수단별 정산 · 정산(개인/공동, 소유자 ⓘ 상세) · 회고(댓글형) · 행사 로그 · **엑셀 내려받기(시트 4개)**
- **전체 기록·비교**: 기간 선택, 행사별 매출·평균선, 행사 비교표, 행사 하이라이트(누르면 해당 위치 강조)
- **재고**: 전체/내 굿즈/위탁 탭, 판매 중·소진(자동)·반환·폐기·삭제, 선택해서 정리·되돌리기, 카테고리·소유자·장르 필터(있는 값만), 엑셀 업로드 ▾(양식 내려받기·엑셀 내려받기), 상품명 호버 썸네일
- **캐릭터톡 · 멤버십·대화권 · 셀러 가이드 투어 · 도움 센터(랜딩 FAQ 연결 자리)**
