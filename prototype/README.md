# 리틀부스 프로토타입 (HTML)

단일 HTML로 만든 화면·흐름 시안이에요. 실제 앱(Flutter, `app/`)을 만들기 전에 컨셉·디자인·기능을 확인하는 용도예요.

## 열기
`prototype/index.html`을 브라우저로 열면 돼요. `account-test1234.js`가 같은 폴더에 있어야 해요.
상단 "기기 미리보기"로 PC·태블릿·모바일 레이아웃을 바꿔 볼 수 있어요.

## 로그인
| 방법 | 데이터 |
| --- | --- |
| 아이디 `test1234` (비밀번호는 아무 값) | 실제 기록: 여의도 음악축제(2026.10.24) + 8월 서코 일요일(일산 킨텍스 BJ04·BJ05) |
| [데모로 둘러보기] | 예시 데이터(망원·성수·한강·홍대 등 가상 행사) |

프로토타입이라 비밀번호를 확인하지 않고, 새로 입력한 내용은 새로고침하면 사라져요. 실제 인증·저장은 `backend/`(Firebase)에서 구현해요.

## test1234 데이터 출처
- **여의도 음악축제**: 레거시 Supabase `booth_workspaces`(test1234, revision 107)의 재고 52종, 판매 13건(초 단위 시각), 방문 84회, 체크리스트·교대 기록을 그대로 옮김.
- **8월 서코 일요일**: 레거시 앱 재고표(상품별 판매가·남은 재고·판매량)와 정산 화면을 기준으로 복원.
  - 합계가 원본과 일치: 총 판매 433,000원(결제 48건), 개인 지급 180,000원(베이시 143,000 · 한재민 35,000 · 조윤선 2,000 · 전채린 0), 공동 253,000원, 현금 13건 85,000 · 계좌이체 33건 330,000 · 카카오페이 2건 18,000, 누적 판매 132개(특전 포토카드 32개 포함).
  - 세트 할인(A·B·C·D) 9,000원은 공동 정산에서 차감.
  - 결제별 구성·시각 기록은 없어서 만들지 않았어요. 결제 내역·시간대별 매출·행사 로그는 "기록 없음"으로 표시돼요.
  - 정확한 날짜(8월 일요일), 방문 수, 원가는 기록이 없어 비워 두었어요 (날짜 미입력 · 방문 "—" · 원가 0원으로 계산).
- 다시 만들기: `tools/seed/`에서 `python3 gen.py <Supabase에서 내보낸 state.json>` → `prototype/account-test1234.js` 갱신. 원본 내보내기 파일은 개인 데이터라 커밋하지 않아요.

## 주요 기능
나의 행사(폴더) · 새 행사 만들기(달력·지난 준비안 불러오기) · 개요·준비(가설+사진, 체크리스트/메모, 반입 상품) · 판매 화면(POS, 옵션·할인·결제수단) · 결과·회고(일별/시간대별, 품목별 매출, 판매 순위, 결제 내역, 결제수단·소유자별 정산, 회고, 행사 로그, 섹션별 CSV) · 전체 기록·비교 · 재고(엑셀 양식/내려받기) · 캐릭터톡 · 멤버십·대화권 · 셀러 가이드 투어.
