# ADR-0002 재고: 소유(내 굿즈/위탁)와 상태

- 배경: 친구들과 함께 나가는 행사마다 위탁 상품을 받아 팔고, 끝나면 남은 재고가 애매해짐. 삭제하면 지난 판매·정산 기록이 깨짐. 내 굿즈만 따로 보고 싶음.
- 결정
  - **소유**: 상품의 소유자가 "내 이름"이면 내 굿즈, 아니면 위탁. 재고 화면 탭 `전체 | 내 굿즈 | 위탁`.
  - **상태**: 판매 중 · 소진(재고 0이면 자동) · 반환 · 폐기 · 삭제. 상품은 지우지 않는다.
    - 반환: 소유자에게 돌려줌. 남은 수량을 재고 이력에 남기고 0으로.
    - 폐기: 손실. 남은 수량을 재고 이력에 남기고 0으로.
    - 삭제: 숨김만(수량 유지), 되돌릴 수 있음.
  - 반환·폐기·삭제 상품은 판매 화면·반입 선택에서 빠지고, 지난 판매·정산·엑셀에는 그대로 남는다.
- 보류: 카테고리 고정 목록(엽서·스티커·문구·아크릴·포스터·뱃지·의류·식품·기타) + 장르 태그 + 상품 변형.
