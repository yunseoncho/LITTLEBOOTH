# ADR-0003 실제 계정에는 기록된 데이터만

- 배경: 서코 결제 48건의 구성·시각을 합계에 맞춰 임의로 만들어 넣었다가 지움(2026-11-10). 옵션(쇼핑백) 수치도 데모 계산식이 실제 행사에 섞여 나옴.
- 결정
  - 실제 계정 화면·엑셀·CSV에는 **원본에 있는 값만** 쓴다. 없는 값은 만들지 않고 "기록 없음"/"—"/"미입력"으로 표시.
  - 합계에서 거꾸로 세부를 만들어 내지 않는다(결제 구성, 시각, 날짜, 방문, 원가 등).
  - 계산값(비율·순수익 등)은 원본 값으로만 계산하고, 화면에 데이터 출처를 적는다.
  - 예시 수치는 **데모 계정에서만** 쓴다.
