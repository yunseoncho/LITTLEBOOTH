# ADR-0005 v1은 과금 요소 없음, AI 없는 캐릭터톡 1종만

- 상태: 제안 (2026-11-11). `docs/strategy/04-business-model.md`의 Plus·대화권(AI 챗) 가설을 v1 범위에서 뺀다.
- 결정: 구독, 대화권(코인), AI 호출을 **모두 제거**한다. 캐릭터는 **1명**, 대화는 **미리 쓴 대본(규칙 기반)**으로 한다.

## 이유
1. 인앱결제를 없애면 심사 위험(3.1.x)과 수수료(15~30%), 세무·정산 업무가 함께 사라진다.
2. AI를 호출하지 않으면 변동 비용과 API 키 유출 위험이 없다. 서버도 필요 없다(ADR-0004).
3. 신뢰와 습관을 먼저 쌓는다는 기존 원칙(04 문서 "현장 도구는 무료")과 맞는다.

## 캐릭터톡 v1 설계 (AI 없음)
- 캐릭터 1명. 새 독자 캐릭터로 확정되기 전까지는 임시 이름·임시 그림을 쓴다 (IP 점검 항목, 보고서 권리 표 참고).
- 대화는 **내 장부 숫자로 문장을 채우는 대본**이다. 예: "오늘 {top}이(가) 가장 잘 나갔어요. 재고가 {left}개 남았어요."
- 트리거: 행사 종료 시 1회, 재고 소진 임박, 목표(가설) 달성/미달. 선택지(버튼)로만 이어 가고 자유 입력은 받지 않는다 → 입력 검증·콘텐츠 신고 기능이 필요 없다.
- 대본은 4개 언어(ko/en/ja/zh-Hans)로 앱 안에 번들한다. 네트워크가 필요 없다.
- 나중에 AI를 넣게 되면 별도 ADR로 결정한다(키는 서버 보관, 호출 한도, 과금 설계 포함).

## 이후 결제 단계 (2차 디벨롭 로드맵)
| 단계 | 내용 | 조건 |
|---|---|---|
| v1.0 | 전부 무료. 결제 SDK·StoreKit 없음 | 출시 |
| v1.x | **응원하기(후원) 1회성 인앱결제** 검토: 기능 잠금 없이 소액 후원 | 사용자 수·반응 확인 후 |
| v2 | 유료 기능은 "행사 비교·성장 리포트·엑셀 내보내기" 같은 분석층부터 구독으로 검토 | 가격 인터뷰 후 |
| v2+ | AI 분석 대화 | 서버·비용·정책 설계 후 |

- 현장 판매(실물 굿즈) 결제는 계속 **기록만** 한다(계좌이체·현금·카카오페이 등). 앱이 돈을 받거나 중개하지 않는다 → 인앱결제 대상이 아니고(3.1.3(e) 취지), PG 등록도 필요 없다. 이 점은 심사 노트에 명시한다.
- 후원·구독을 넣을 때는 반드시 StoreKit(인앱결제)로만 받는다. 외부 결제 링크는 지역별 규정이 다르므로 넣기 전에 최신 가이드라인을 확인한다.

## 정리해야 할 프로토타입 화면
- 멤버십(Plus 4,900원/월) 카드, 대화권 충전·가격표, "캐릭터톡 하루 1번" 문구, 사이드바 Plus 안내 → v1 앱에는 만들지 않는다.
