# 무료로 쓸 만한 API·서비스 조사 (2026-11)

**원칙: 외부 API를 최소로 쓴다.** 이 앱은 서버가 없고(ADR-0004) 수집 데이터가 없는 것이 강점이다. 외부 호출을 하나 넣을 때마다 (1) 키를 앱에 넣어야 하는지(유출 위험), (2) 무료 약관이 상업 이용을 허용하는지, (3) 개인정보 라벨이 바뀌는지를 먼저 본다.
우선순위: **① 기기 안에서 해결 → ② 앱에 데이터를 번들 → ③ 키 없는 공개 API → ④ 키가 필요한 API(서버가 생긴 뒤)**

## 근거와 주의
**CloudKit** — 개인(private) 데이터베이스에 저장한 데이터는 개발자가 아니라 **사용자의 iCloud 저장 용량**으로 계산된다([Apple 문서](https://developer.apple.com/documentation/cloudkit/ckcontainer)). 그래서 서버 없이, 개발자 비용 없이 백업·동기화를 줄 수 있다. 주의: 사용자 용량이 가득 차면 `quotaExceeded`가 나므로 앱 안에서 안내해야 하고, Expo에서는 네이티브 모듈이 필요하다. 공유 데이터는 원 소유자의 용량으로 계산된다. *(포럼 글 중 일부는 오래된 정보라, 도입 전에 현재 Apple 문서로 재확인)*

**환율: Frankfurter** — 키 없이 쓰는 무료 API이고 FAQ상 상업 이용 가능, 공식 인스턴스에 알려진 요율 제한은 없다([frankfurter.dev](https://frankfurter.dev/)). ECB 기준 일 단위 환율이라 실시간이 아니다. **KRW·CNY가 포함되는지는 이번 조사에서 직접 확인하지 못했다** → 도입 전에 v2 엔드포인트에서 해당 통화를 호출해 본다. 행사별로 통화를 하나만 쓰는 v1에는 필요 없다.

**날씨: Open-Meteo는 피한다** — 무료 API는 **비상업(non-commercial) 용도에 한정**이고(공식 [이용약관](https://open-meteo.com/en/terms)), 일 약 1만 건이 한도로 알려져 있다. 지금은 무료 앱이어도 이후 유료 기능을 넣으면 상업 이용이 되어 약관 위반이 된다. 한국 기상청 공공데이터는 서비스 키가 필요한데 앱에 넣으면 유출된다. 그래서 v1.x는 사용자가 날씨를 직접 고르게 하고(0원·무위험), 자동 날씨는 서버가 생긴 뒤 다시 본다. *(Apple WeatherKit의 네이티브 API는 키 없이 쓸 수 있고 개발자 프로그램에 월 호출량이 포함된다고 알려져 있으나, 이번에 한도를 확인하지 못했다.)*

**공휴일** — 한국천문연구원 특일 정보는 [공공데이터포털](https://www.data.go.kr)에서 활용 신청 후 서비스 키를 받는 방식이다. 일일 호출 한도와 이용허락 범위는 상세 페이지에서 확인해야 한다(블로그 등에서는 1,000~10,000회로 엇갈림, **공식 수치 미확인**). 앱에서 직접 호출하면 키가 앱에 들어가므로, **개발 머신에서 1년에 한 번 받아 JSON으로 번들**한다. 일본·중국·미국 휴일은 각 국가의 공식 공고를 기준으로 같은 방식으로 만든다.

**송금** — 앱은 돈을 받거나 중개하지 않고 **기록만** 한다(ADR-0005). 셀러가 자기 계좌 QR(은행·토스·카카오페이 앱에서 만든 이미지)을 한 번 등록해 손님에게 보여 주면 된다. 토스·카카오페이의 송금 딥링크는 공식 문서를 확인하지 못해 **쓰지 않는다**(비공식 링크는 예고 없이 바뀐다).

**빌드 비용** — EAS 무료 등급은 월 iOS 15회 빌드, 저우선 대기열, 빌드당 45분 제한으로 안내하는 자료가 많다. 출처마다 숫자가 달라 [expo.dev 요금 안내](https://docs.expo.dev/billing/plans/)에서 확인해야 한다. EAS Submit은 모든 요금제에 포함된다고 안내된다. Apple Developer Program 연 99달러는 피할 수 없다.

## 쓰지 말 것 (함정)
- **앱에 API 키를 넣는 모든 서비스**(공공데이터포털 직접 호출, 지도·날씨·번역 키). 앱 바이너리에서 키를 꺼내는 것은 쉽다.
- **무료 등급이 비상업인 서비스**(Open-Meteo 등) — 유료 기능을 넣는 순간 위반.
- **Firebase Functions/Blaze** — 무료 시작처럼 보여도 결제 수단 등록이 필요하고 비용이 예측 불가.
- **지도 SDK** — 대개 결제 계정 등록이 필요하다. 행사 장소는 문자로 충분하다.
- **분석·광고 SDK** — "데이터 수집 안 함" 라벨과 신뢰가 깨진다.
- **AI API** — 변동 비용·키 유출·정책 부담(ADR-0005). 나중에 필요하면 기기 안에서 도는 모델을 먼저 본다.
