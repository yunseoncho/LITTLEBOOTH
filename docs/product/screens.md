# 화면·기능 명세 (프로토타입 v73 기준)

Flutter 구현의 기준 문서. 화면 모양은 `prototype/index.html`을 그대로 참고하고, 여기엔 **규칙**만 적어요.

## 공통
- 계정: 로그인(아이디·비밀번호) / 데모 둘러보기. 데모는 예시 데이터, 실제 계정엔 **기록된 데이터만** 보여요([ADR-0003](../decisions/0003-real-data-only.md)).
- 기기: PC(사이드바) · 태블릿(레일) · 모바일(하단 탭). 라이트 모드, 색은 회색 + 브랜드 분홍(#FF4F8B). 강조가 필요한 숫자만 예외(결제 금액 파랑).
- 글로벌: 셀러 가이드 투어, 도움 센터(랜딩 FAQ 고객센터 메일로 이동), TOP 버튼(500px 이상 스크롤 시).

## 행사
| 탭 | 내용 | 규칙 |
| --- | --- | --- |
| 개요·준비 | 가설(글·사진) + 오른쪽 블럭, 반입 상품 | 블럭: 준비 중=체크리스트, 운영 중=공지·현장 메모, 종료=두 탭 |
| 판매 기록 | 요약 + 결제 내역 | 결제마다 날짜·시:분:초, 결제수단, 상품·단가×수량, 할인. 결제별 기록이 없으면 "기록 없음" |
| 결과·회고 | 아래 표 | 이번 행사 내용만(지난 행사 비교 없음) |

### 결과·회고 구성
1. 요약: 매출·주문·객단가·방문(기록 없으면 —)
2. 일별 / 시간대별(꺾은선, 최고 시간 분홍) / 방문 시간대(5분 막대 + 시간당 추이 곡선). 시각 기록이 없으면 표시하지 않음
3. 품목별 매출: 막대 하나를 카테고리 비율로 나눔, 호버 상세
4. 판매 순위: 상품/옵션/카테고리, 정렬(개수·금액·순수익), 반입 대비 판매율, 매출 비중, 순수익(=판매금액−원가, 할인은 합계에서만), 5위 아래 펼치기
5. 결제수단별 정산(건수·금액)
6. 정산: 총 판매금액 / 개인 지급 / 공동 정산(할인 차감), 담당자별 ⓘ → 판매 내역·상품별 합계
7. 회고(댓글형), 행사 로그(준비→운영→종료, 시각 있는 기록만)
8. 엑셀 내려받기 — 시트: `개요`(제목·날짜·장소·출처·요약) · `품목·판매`(품목별 매출·판매 수익) · `정산`(결제수단·소유자별·요약·합계) · `판매 기록`(결제 시각순, 주문 결제금액 열 노란색·같은 주문 병합, 주문 단위 배경색)

## 판매 화면(POS)
- 탭: 즐겨찾기 + 반입 상품의 카테고리. 상품 추가·편집은 여기서 하지 않음(재고 관리에서만).
- 주문 줄을 누르면 그 줄 아래에 수량·옵션(선물 포장·쇼핑백)·삭제. 금액 깎기는 [할인]으로만.
- 결제수단: 카드·현금(거스름돈)·계좌이체·카카오페이. 방문 +1은 시각과 함께 저장.

## 재고 ([ADR-0002](../decisions/0002-inventory-ownership-status.md))
- 탭: 전체 / 내 굿즈 / 위탁 — "내 이름"으로 고른 소유자의 상품이 내 굿즈
- 상태: 판매 중 · 소진(재고 0이면 자동) · 반환 · 폐기 · 삭제. 선택해서 정리, 정리된 탭에서 되돌리기
- 필터: 카테고리·소유자·장르 선택칸(지금 조건에 상품이 있는 값만), 정렬. 검색은 상품명·초성·소유자·장르
- 엑셀: [엑셀 업로드 ▾] → 양식 내려받기(카테고리 드롭다운·필수 항목·필터 상태면 미리 채움) / 엑셀 내려받기(지금 목록)
- 상품명 호버 → 사진 미리보기

## 전체 기록·비교
- 제목의 기간(1·2·3개월·전체·직접 지정) 드롭다운, 참여한 부스·총매출(부스당 평균)·주문·평균 객단가
- 행사별 매출 막대 + 평균 점선 + 날짜 캡션, 행사 비교표
- 행사 하이라이트 3개: 매출 1위 상품 / 최고 매출 행사 / 가장 바쁜 시간(시각 기록 있는 행사만). 누르면 그 행사의 해당 위치를 강조

## 미결정
- 카테고리 고정 목록 + 장르 태그 + 상품 변형(1-1~1-4를 한 상품으로) 도입 여부
- 여의도 "명함 500원 할인" 결제를 할인으로 반영할지
- 서코 방문 수·원가 입력 (날짜·결제 내역은 2026-08-16 결제 내보내기로 반영됨)
