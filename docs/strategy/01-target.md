# 01. 타겟

## 핵심 타겟: "행사를 도는 1인·소규모 셀러"
- 팝업스토어·플리마켓·굿즈/핸드메이드/디저트 부스를 월 1~8회 운영
- 혼자 또는 1~2명이 운영, 현장에서 엑셀·메모·카톡으로 기록
- 20~40대, 모바일(iPhone) 중심. 행사 후 정산·회고는 대부분 감으로 한다

## 해결할 문제 (Job to be done)
| 상황 | 지금 | 리틀부스가 하는 일 |
|---|---|---|
| 현장 판매 | 종이·메모, 바빠서 누락 | 한 손 POS, 오프라인에서도 기록 |
| 행사 끝 | "얼마 벌었지?" 계산 | 즉시 정산·원가·순이익 |
| 다음 행사 준비 | 감으로 재고·가격 | 지난 행사 데이터 기반 제안 |
| 행사 선택 | 어디가 잘 됐는지 기억 의존 | 행사·장소·요일 비교 |
| 동기 | 혼자라 외롭고 성과가 안 보임 | 성장 기록과 캐릭터 |

## 확장 타겟 (후순위)
1. 셀러의 알바·동행 (공동 기록) — M2 이후
2. 행사 주최사·브랜드 (참가 셀러 현황, 제휴) — PC 오피스 단계

## 검증 필요 (가설)
- 기록 앱을 이미 쓰는 셀러가 "분석·성장"에 돈을 낼지
- 아이폰 비중과 타겟의 행사 빈도 → 인터뷰 10명, 여의도 현장 피드백 재활용
