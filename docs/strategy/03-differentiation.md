# 03. 차별점

## 시장 구도
- **기록형 앱**(예: 파라바라 류): 판매·재고·정산을 편하게 기록. 이미 있고 무료/저가 경쟁.
- **엑셀/메모**: 대다수의 실제 경쟁자.
- 리틀부스는 기록을 **기본기로 맞추고**, 그 위에서 이긴다.
> 파라바라 등 경쟁 앱의 상세 기능은 확인하지 못했다. 스토어 페이지로 대조 필요.

## 차별점 5가지
1. **기록 → 성장**: 행사 간 비교, 요일·장소·메뉴·가격 인사이트, "다음 행사에 이렇게" 제안.
2. **대화형 분석**: 캐릭터 AI 챗이 장부를 읽고 말해 준다. 숫자 해석 부담을 없앤다.
3. **컨셉이 곧 제품**: 성장 서사·캐릭터·톤이 일관된 브랜드. 기록 앱 중 가장 "애착이 가는" 앱.
4. **현장 우선 설계**: 오프라인 우선 POS, 한 손 조작, 즉석 할인·거스름돈·취소 이력.
5. **셀러 오피스로 확장**: 모바일(현장) + PC(분석·관리·내보내기). 카페24처럼 사업이 커져도 계속 쓰는 관리 도구.

## 지킬 것 / 버릴 것
- 지킬 것: 판매·재고 일관성(revision), 주문 멱등, 취소 이력
- 버릴 것: 레거시의 기능 나열식 화면, 단일 JSON 상태 저장
